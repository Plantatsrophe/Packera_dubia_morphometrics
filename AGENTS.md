## 1. Non-Negotiable Code and Documentation Hygiene

* **Zero `_archive` Coupling:** Never import, source, read, or fall back to `scripts/_archive/`, `data/_archive/`, or `outputs/_archive/`. Active code must fail fast if inputs are missing.
* **Zero Obsolete Framework Remnants:** Operates purely on LeafMachine3 (`lm3`) ONNX Runtime and modern PyTorch/R stacks. Active files must contain zero obsolete ML or segmentation framework remnants and zero obsolete helper tokens.
* **Dynamic Genus-Wide Discovery:** Queries genus-wide occurrences dynamically through `discover_genus_packera_species_gbif()`. CLI `--taxon` or `--focal-taxon` runs restrict analysis strictly to specified taxa.
* **Positive Present-State Documentation:** Maintain all documentation strictly in terms of active capabilities, positive requirements, and current implementations. Never define system behavior by referencing removed subsystems or documenting negative omissions.
* **Zero Silent Synthetic Data:** Never generate unflagged random embeddings (`np.random.randn`), static Gaussian heatmaps, or trigonometric environmental values. Synthetic generation requires explicit `--demo` (`PACKERA_DEMO_MODE=1`), which isolates writes to ephemeral SQLite (`demo_ephemeral.sqlite`) and never touches canonical stores.
* **Authentic Voice and Documentation Standard (`@write-in-my-voice`):** All prose, documentation, SOP descriptions, and README sections must follow Brandon Fuller's authentic voice (Writing DNA v5.2 in `.agents/skills/write-in-my-voice/SKILL.md`). Enforce zero em dashes, zero en dashes, zero banned AI buzzwords, and active first-person empirical framing.
* **Dual Virtualenv Boundaries:**
  * `.venv`: Primary orchestration (`main.py`, `run_pipeline.sh`), DuckDB, general scientific tools.
  * `.venv_LM3`: LeafMachine3 ONNX Runtime isolation (YOLO26x, UNet++ v9, Ruler solver, ECT), relying strictly on standard-library `sqlite3` without compiled C/C++ database drivers.
* **Verification Gate:** Verify code hygiene via `pytest scripts/tests/test_code_hygiene.py -q`.

## 3. Two-Tier Storage Architecture and Relational Contracts

Central SQLite WAL database (`data/packera_pipeline.sqlite`) paired with synchronized atomic CSV snapshots:
* **Tier A: Canonical Shared Store (`data/`):** Invariant Step 01 to 02 assets, masks, 120-vertex contours, crops, environmental cache, and canonical tables.
* **Tier B: Run-Scoped Stores (`runs/<RUN_ID>/` with `runs/latest`):** Active cohort filtering, Step 03 to 07 statistics, reports, figures, and run logs.

### Mandatory Cross-Language Schema and Handoff Invariants
* **Composite Grouping Key `(catalogNumber, plant_individual_id)`:** All joins across Python and R must group by this composite key. Never collapse multi-plant sheets to `plant_individual_id = 0` or group by `catalogNumber` alone.
* **Schema Contract Version (`PACKERA_SCHEMA_USER_VERSION = 20260407`):** Relational tables and views must maintain schema synchronization across Python (`db_schema.py`) and R (`db_utils.R`), supporting dynamic column migrations for OSR metrics, label noise flags, and population cohesion indicators.
* **Routing Tier `assigned_tier`:** `'Tier_1_Direct'` (intact silhouettes for EFA) vs `'Tier_2_Reflected'` (folded blades for linear traits). In R, match case-insensitively: `grepl("^tier_?[12]", assigned_tier, ignore.case = TRUE)`.
* **Scale and Geometry:** Empirical `pixels_per_mm` and boolean `is_calibrated_mm`. Native LeafMachine3 stride-32 letterboxing (`auto=True, stride=32`), `overlap = 0.95` Stage 1 nested-box deduplication, `Specimen_Segmenter` UNet++ v9 + `paperclean_llr_hyst_keepblobs` in CIE $L^*a^*b^*$ space at `max_working_dim = 3200`, tight `crop_pad = 0.0` Stage 2 leaf crops with `Leaf_Segmenter` `retina_masks: true`, `report.masks.subtract_holes: true`, topology-aware inter-lobe sinus bridge opening in `_prepare_lamina_mask()` and `classify_and_route_leaf()` so 120-vertex contours trace around lobes without background paper, and $32 \times 32$ ECT matrices. Per-plant (`plant_individual_id`) adaptive blade floor $\min(0.75, \max(0.15, 0.25 \times \text{median\_area}))$ and relative area floor ($0.15 \times \max\text{area}$) without a sheet-wide leaf cap. Petiole $L_{\text{petiole}}$ from crown $p_{\text{crown}}$ at $P_{75}$. Scape height $H_{\text{plant}}$ accounts for bent stems. Rosette background masked to `[242, 239, 230]`.
* **Nomenclatural Types and Authority:** Strict `identifiedBy` isolation (`parse_determiner_tier()` and `classify_determiner_tier()`) evaluates determiners independently of `recordedBy`, matches curated North American *Packera* specialists (`PACKERA_SPECIALISTS` and `SPECIALIST_PATTERNS`), blocks non-person database adjustments (`"Nomenclatural Adjustment"`, `"Nomenclature update"`, `"Taxonomic update"`, `"Annotation"`), and blocks bare common surnames without initials. Multi-herbarium monographer loan protection in `apply_corpus_authority_tiers()` preserves `Tier_1_Gold` for specialists annotating across multiple species or herbaria even when `dateIdentified` is missing, while single-folder institutional batch-transfer demotion routes undated single-herbarium, single-species batch transfers ($\ge 25$ sheets, $\ge 10$ collectors, $\ge 85\%$ in 1 species at 1 institution where `recordedBy != identifiedBy`) from `Tier_1_Gold` to `Tier_2_Silver` for out-of-sample Mahalanobis and Confident Learning screening; personal field collections (`recordedBy == identifiedBy`) and dated specialist annotations remain `Tier_1_Gold`. Preflight re-applies `apply_corpus_authority_tiers()` and filters `--auto-neighbors` candidates against `^Packera\s+[a-z]{3,}$`. Ranks 2 and 1 exempt from uncertainty and date drop filters, retained in spatial thinning, prioritized in outgroups. Supervised anchors (`Tier_1_Gold`, `Tier_2_Silver`, promoted Bronze within $\chi^2_{0.80}$) fit models; unpromoted Bronze receive $0.0$. Type retention immunity (`Tier_0_Type_Anchor`); extreme types ($> \chi^2_{0.99}$) isolated from FastMCD. Centers shrink toward type medoids ($\gamma_k$).
* **Strict Tier-1 EFA (Step 03):** Batch SQL from `contour_xy_json`. `coo_alignxax`, dynamic $H_{\text{opt}} \in [6, 24]$ ($\ge 99\%$ power), `rm_asym`, $k_{95}$ variance PCs. Type contours exempt from MCD filtering. OTU aggregation with Level 1 basal rosette ($w_{\text{basal}} = 1.0$) vs. cauline bract ($w_{\text{cauline}} = 0.35$) heteroblasty weighting.
* **Morphometrics and Allometry (Step 04):** 3-level hierarchical variance decomposition and Empirical Bayes shrinkage across Level 1 within-plant heteroblasty ($w_{\text{basal}} = 1.0$, $w_{\text{cauline}} = 0.35$), Level 2 same-sheet gathering (`catalogNumber` / `exsiccatae_key`, $\kappa_{\text{sheet}} = 1.5$), and Level 3 conspecific $10\text{ km}$ spatial population-center (deme) shrinkage (`apply_hierarchical_population_deme_shrinkage`, $\kappa_{\text{deme}} = 1.25$). Two-stage FastMCD reference anchor seeding fits initial ellipsoid on Gold and Type anchors ($\chi^2_{0.95, p}$ for $n \ge \max(12, 5p)$) and screens Silver anchors at $\chi^2_{0.90, p}$. Dissected-leaf sub-mode splitting requires $\ge 25\%$ `Tier_1_Gold` dissected support for entire-leaved basal species. Out-of-fold Confident Learning screens anchors via shrinkage posteriors, demoting violators (`is_confident_label_noise = TRUE`) to passive projection. Crossed-effects hierarchical Bayesian authority weights evaluate leave-one-out PC concordance unconditionally when $G \ge 2$, combining determiner reliability $\theta^{\text{det}}_d$ and herbarium reliability $\theta^{\text{inst}}_h = \frac{4.0 \cdot 0.85 + \sum_{i \in h} c_i}{4.0 + n_h}$ in log-odds space with Raykar multiplicative updates. Canonical GMM relabeling fixes Cluster 1 ($c^* \equiv 1$) to the nomenclatural type medoid or highest-weighted Gold core while `compute_type_specimen_morph_control()` evaluates `is_typical_morphotype` per species ($c^*_k$), with $N_{\text{eff}}$-scaled Bayes Factors ($2\Delta\text{BIC} \cdot N_{\text{eff}} / N_{\text{core}}$). Feature pools incorporate foliar architecture metrics (`blade_length_to_width_ratio`, `petiole_to_blade_ratio`, `basal_vs_cauline_length_ratio`, `dissection_index`, `solidity`). Soft Gaussian geographic range-envelope log-prior ($3.5^\circ$ MAD floor). Klingenberg allometric slope homogeneity (`lm.rrpp`). Horn/Williams-Titus subspace. Shrinkage CDA with honest LOOCV. Open-Set Recognition exports `min_congener_mahal_d2`, `min_congener_taxon`, and `open_set_novelty_p`.
* **Spatial RF and *Locus Classicus* (Step 05):** Passive projection of non-Tier-1 specimens lacking a Step 04 `gmm_cluster` (`is_missing_gmm_cluster`). 19 BioClim + 0 to 15 cm edaphics. Uncertainty-gated type extraction ($\le 2000\text{ m}$ edaphic, $\le 10000\text{ m}$ climatic) with proximate Gold fallback ($\le 150\text{ km}$). Predictor gating (VIF $< 5.0$, $|r| < 0.70$, RF importance top 85%). Spatial Block CV ($0.5^\circ$) with weights `[0.25, 4.0]`. MaxEnt + Spatial RF.
* **Consensus Triage and Complexes (Steps 06 to 07):** Reliability weighting via out-of-fold $\kappa_m$. Circular anthesis DOY windows. Sibling ramet morphology propagation across multi-plant sheets (`catalogNumber`), requirement of observed or sheet-propagated leaf morphology before scoring `Putative_Hybrid_Introgression` / `Hybrid_Introgressant` (never imputing `cda_margin = 0.15` on leafless ramets), and same-sheet (`catalogNumber`) gathering coherence across sibling `plant_individual_id` ramets. Stage 1 (`Misidentification_Reassign`) and relative Open-Set congener reassignment (`congener_osr_reassign`: $\chi^2_{0.90, p}$, $D^2_{\text{Mahal}}(k') < 0.70 \cdot D^2_{\text{Mahal}}(y_i)$, and $D^2_{\text{Mahal}}(y_i) > \chi^2_{0.95, p}$) evaluated strictly before Stage 3 (`Putative_Cryptic_Species`), using calibrated CDA thresholds (`0.72` / `0.68` / `0.62`), radial edaphic fallback, and orthogonal 1-vote-per-modality Rule B (`vote_morph` + `vote_edaph`) with morphological concordance protection (`cda_prob >= 0.65`). Population-Cohesion Lineage Gate requires `cryptic_cluster_cohesion_pass == TRUE` ($\ge 5$ independent collection events across $\ge 2$ collectors or herbaria, cluster-median `min_congener_mahal_d2` $> \chi^2_{0.95, 3}$, and $\ge 50\%$ concordant ecological or phenological divergence with $\text{BF} \ge 10.0$); non-cohesive clusters route to `Confirmed_Species` (*sensu lato*), `Ecophenotypic_Plasticity`, or `Subspecies_Ecotype`. Rule A (type immunity / `Confirmed_Type_Control`), Rule B (reassignment), Rule C (*sensu stricto* locking for $c^*_k$). Unsupervised graph modularity (Leiden/Louvain) and Ward.D2 clustering across North American *Packera*.
