## 1. Non-Negotiable Code and Documentation Hygiene

* **Zero `_archive` Coupling:** Never import or source files from `scripts/_archive/`, `data/_archive/`, or `outputs/_archive/`. Active code must fail fast when required inputs are missing.
* **Zero Obsolete Framework Remnants:** The pipeline operates purely on LeafMachine3 (`lm3`) ONNX Runtime and modern Python and R statistical stacks without modifying files inside `LeafMachine3/`. Active files must contain zero obsolete segmentation framework remnants and zero retired helper tokens.
* **300-DPI PNG-Only Figure Architecture:** All 14 canonical publication plates (`fig02a` through `fig07b`) and native `LeafMachine3` visual caches (`lm3_assets/`, `ect_overlays/`, and `lm3_sheet_overlays/`) export strictly as 300-DPI `.png` rasters (`0` `.pdf` figure outputs) with unfilled hollow scatterplot symbols, combinatorial 60-taxon palette-and-shape scaling, and ICN rank-aware italicization.
* **Dynamic Genus-Wide Discovery:** The harvester queries genus-wide occurrences dynamically through `discover_genus_packera_species_gbif()`. Explicit `taxon` or `focal_taxon` runs restrict analysis strictly to the specified taxa and reconcile SQLite `vouchers` with `curated_vouchers.csv` via `reconcile_curated_vouchers_csv_with_db()`.
* **Positive Present-State Documentation:** Maintain all documentation strictly in terms of active capabilities and positive requirements alongside current implementations.
* **Zero Silent Synthetic Data:** Never generate unflagged random embeddings (`np.random.randn`) or synthetic raster values when `demo` mode is inactive. Synthetic data generation requires explicit `demo` mode (`PLANTMATICS_DEMO_MODE=1`, with `PACKERA_DEMO_MODE=1` compatibility), which isolates writes to ephemeral SQLite (`demo_ephemeral.sqlite`) and leaves canonical stores untouched.
* **Authentic Voice and Documentation Standard (`@write-in-my-voice`):** All prose and SOP descriptions alongside `README.md`, `AGENTS.md`, `CONTRIBUTING.md`, `CHANGELOG.md`, and `docs/*.md` must follow Brandon Fuller's authentic voice (Writing DNA v5.2 in [`.agents/skills/write-in-my-voice/SKILL.md`](.agents/skills/write-in-my-voice/SKILL.md)), with zero em dashes, zero en dashes, zero tricolons, zero trailing participial clauses, and active first-person empirical framing.
* **Dual Virtualenv Boundaries:**
  * `.venv`: Primary orchestration (`main.py`, `run_pipeline.sh`), environmental layer downloads, and DuckDB/SQLite management.
  * `.venv_LM3` (`LeafMachine3/.venv`): LeafMachine3 ONNX Runtime isolation (YOLO26x, UNet++ v9, Ruler solver, ECT, and visual product rendering), relying strictly on standard-library `sqlite3`.
* **Verification Gate:** Verify code hygiene and cross-stage contracts via `.venv/bin/python scripts/tests/run_audit.py` (or `.venv/bin/python scripts/tests/run_audit.py --fast` for rapid Python-only iteration before running the full warm-R audit).

## 3. Two-Tier Storage Architecture and Relational Contracts

The central SQLite WAL database (`data/plantmatics.sqlite`, automatically migrated atomically without data loss from legacy `data/packera_pipeline.sqlite`; configurable via `PLANTMATICS_DB_PATH`, `PLANTMATICS_RUN_DIR`, `PLANTMATICS_GENOMICS_DIR`, plus `PLANTMATICS_CYTOLOGY_DIR` with `PACKERA_*` fallback compatibility) pairs with synchronized atomic CSV snapshots:
* **Tier A: Canonical Shared Store (`data/`):** Houses invariant Step 01 and Step 02 specimen records, WebP scans, binary masks, 120-vertex tip-up contours, $32 \times 360$ ECT `.npy` matrices, organ crops, canonical manifests, the environmental cache, `usda_county_ranges`, `step_telemetry_benchmarks`, flat `data/taxonomy/` backbone/NatureServe/`public_taxonomic_specialists.csv` tables, flat `data/cytology/` chromosome/C-value tables, plus `genomic_samples` metadata/QC.
* **Tier B: Run-Scoped Stores (`runs/<RUN_ID>/` with `runs/latest`, `runs/latest_run.json`, and `runs/latest_eastern_na`):** Isolates active cohort filtering and Step 03 to 07 statistical tables alongside written reports, per-step `logs/progress.jsonl` telemetry streams, geospatial rasters, and 300-DPI PNG figures. Both flat single-level `run_id` keys (`runs/<RUN_ID>/` linked by `runs/latest` and `runs/latest_run.json`) and nested hierarchical monograph `run_id` keys (`<PARENT_RUN_ID>/00_genus_wide/<Stage>` and `<PARENT_RUN_ID>/<Species_Slug>/<Stage>` inside `runs/<PARENT_RUN_ID>/`, linked by `runs/latest_eastern_na`) resolve losslessly across Python and R as well as Bash and stay strictly isolated by `run_id` inside SQLite Tier B tables.
* **Segment and Run Reset (`purge-segments` / `purge-old-data`):** Invoking `purge_segments_and_runs()` in `scripts/core/db.py` clears Step 02 to 07 masks, contours, ECT matrices, organ crops, downstream CSVs, `runs/`, and SQLite Step 02 to 07 rows (`VACUUM`), whereas Step 01 `vouchers`, `taxon_synonyms`, `usda_county_ranges`, `taxon_backbone_profiles`, `natureserve_subnational_ranges`, `taxonomic_specialists`, `environmental_cache`, `step_telemetry_benchmarks`, `genomic_samples`, `cytological_records`, `taxon_cytology_summary`, `data/raw_vouchers/`, `data/taxonomy/`, `data/cytology/`, `data/genomics/`, plus `data/tables/curated_vouchers.csv` remain intact (non-destructive Tier B `purge-runs-only` resets likewise preserve Step 02 imagery/contours, `genomic_samples`, Tier A taxonomic backbone and specialist tables, plus Tier A cytology tables).

* **Genus-Agnostic Config, Trinomial Rank & Growth-Form Scoping (`TaxaConfig`):** Config readers and harvesters resolve active genus, family, infraspecific rank policy, and growth-form preset dynamically via `PLANTMATICS_TARGET_GENUS`, `resolve_target_genus()` (`"Packera"` default), `resolve_target_family()` (`"Asteraceae"` default), `resolve_infraspecific_rank_policy()` (`"collapse_to_species"` vs. `"preserve_accepted_trinomials"`), `resolve_growth_form_preset()` (`"rosette_herb"`, `"cauline_herb"`, `"woody_branch"`, `"compound_leaf"`, `"graminoid_linear"`, `"non_laminate_bypass"`), `standardize_taxon_name()`, and R `resolve_r_target_genus()` paired with `resolve_r_growth_form_preset()`, `is_active_genus_binomial()` (matching accepted `subsp.`/`var.`/`nothosubsp.`/`nothovar.` trinomials via POSIX regexes), `abbreviate_binomial()`, and `UNASSIGNED_TAXON_SENTINEL` (`"Unassigned_Taxon"`), so non-*Packera* lineages such as *Solidago*, *Quercus*, *Salix*, and *Viola* execute cleanly without source edits.
* **Read-Only LeafMachine3 Step 02 Adapter and Step 03 R EFA QC:** Step 02 persists 100% of `LeafMachine3` segmented leaves, native symmetry/QC metrics, 120-vertex tip-up `lamina_base`-anchored contours, and $32 \times 360$ ECT matrices to SQLite without destructive Python-side leaf dropping; Step 03 (`evaluate_step03_lm3_efa_qc`) filters unresolved clumps in R before running `coo_center() %>% coo_scale()` and `Momocs::efourier(..., norm = FALSE, start = FALSE)` (preserving reniform/obovate $L/W < 1.0$ homology without `norm = TRUE` ellipse flipping).
