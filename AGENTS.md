## 1. Non-Negotiable Code and Documentation Hygiene

* **Zero `_archive` Coupling:** Never import or source files from `scripts/_archive/`, `data/_archive/`, or `outputs/_archive/`. Active code must fail fast when required inputs are missing.
* **Zero Obsolete Framework Remnants:** The pipeline operates purely on LeafMachine3 (`lm3`) ONNX Runtime and modern PyTorch/R stacks. Active files must contain zero obsolete ML or segmentation framework remnants and zero obsolete helper tokens.
* **Dynamic Genus-Wide Discovery:** The harvester queries genus-wide occurrences dynamically through `discover_genus_packera_species_gbif()`. Explicit `taxon` or `focal_taxon` runs restrict analysis strictly to the specified taxa and reconcile SQLite `vouchers` with `curated_vouchers.csv` via `reconcile_curated_vouchers_csv_with_db()`.
* **Positive Present-State Documentation:** Maintain all documentation strictly in terms of active capabilities and positive requirements alongside current implementations. Never define system behavior by referencing removed subsystems or documenting negative omissions.
* **Zero Silent Synthetic Data:** Never generate unflagged random embeddings (`np.random.randn`) or static Gaussian heatmaps alongside trigonometric environmental values. Synthetic generation requires explicit `demo` mode (`PACKERA_DEMO_MODE=1`), which isolates writes to ephemeral SQLite (`demo_ephemeral.sqlite`) and never touches canonical stores.
* **Authentic Voice and Documentation Standard (`@write-in-my-voice`):** All prose and SOP descriptions alongside README and agent documentation must follow Brandon Fuller's authentic voice (Writing DNA v5.2 in `.agents/skills/write-in-my-voice/SKILL.md`). Enforce zero em dashes and zero en dashes alongside zero tricolons alongside zero trailing participial clauses and active first-person empirical framing.
* **Dual Virtualenv Boundaries:**
  * `.venv`: Primary orchestration (`main.py`, `run_pipeline.sh`) and DuckDB alongside general scientific tools.
  * `.venv_LM3` (`LeafMachine3/.venv`): LeafMachine3 ONNX Runtime isolation (YOLO26x, UNet++ v9, Ruler solver, ECT), which relies strictly on standard-library `sqlite3` without compiled C/C++ database drivers.
* **Verification Gate:** Verify code hygiene via `pytest scripts/tests/test_code_hygiene.py -q` and `python scripts/tests/run_audit.py`.

## 3. Two-Tier Storage Architecture and Relational Contracts

The central SQLite WAL database (`data/packera_pipeline.sqlite`) pairs with synchronized atomic CSV snapshots:
* **Tier A: Canonical Shared Store (`data/`):** Houses invariant Step 01 to 02 assets and masks alongside 120-vertex contours and $32 \times 32$ ECT `.npy` matrices alongside organ crops and canonical tables with the environmental cache.
* **Tier B: Run-Scoped Stores (`runs/<RUN_ID>/` with `runs/latest`):** Isolates active cohort filtering and Step 03 to 07 statistics alongside reports and publication figures with run logs.
* **Segment and Run Reset (`purge-segments` / `purge-old-data`):** When you run `run_pipeline.sh` or `main.py` alongside `02_segment_and_extract.py` with the segment purge option, `purge_segments_and_runs()` in `scripts/core/db.py` wipes Step 02 to 07 masks, contours, ECT matrices, crops, tables, `runs/`, and SQLite rows (`VACUUM`), whereas Step 01 `vouchers`, `taxon_synonyms`, `environmental_cache`, `data/raw_vouchers/`, and `data/tables/curated_vouchers.csv` remain intact.

### Mandatory Cross-Language Schema and Handoff Invariants
* **Composite Grouping Key `(catalogNumber, plant_individual_id)`:** All joins across Python and R must group by this composite key. Never collapse multi-plant sheets to `plant_individual_id = 0` or group by `catalogNumber` alone.
* **Schema Contract Version (`PACKERA_SCHEMA_USER_VERSION = 20260407`):** Relational tables and views must maintain schema synchronization across Python (`db_schema.py`) and R (`db_utils.R`), which supports dynamic column migrations for OSR metrics and ECT descriptors alongside label noise flags and population cohesion indicators.
* **Routing Tier `assigned_tier`:** `'Tier_1_Direct'` (intact silhouettes for EFA) vs `'Tier_2_Reflected'` (folded blades for linear traits). In R, match case-insensitively: `grepl("^tier_?[12]", assigned_tier, ignore.case = TRUE)`.
* **Scale and Stage 1/2 Computer Vision Geometry:** Empirical `pixels_per_mm` and boolean `is_calibrated_mm`. Native LeafMachine3 `max_working_dim = 3200` working-frame ingest uses dynamic rectangular stride-32 letterboxing (`auto=True, stride=32`) across `yolo26x_det_1280` (`conf = 0.25`, `iou = 0.55`, `include_partial = true`) and `yolo26x_seg_1024` alongside `yolo26x_pose_640`. Stage 1 enforces parent-preserving asymmetric nested-box deduplication (`overlap = 0.95`), which retains enclosing parent whole-leaf boxes over nested terminal-lobe boxes. `Specimen_Segmenter` UNet++ v9 runs `paperclean_llr_hyst_keepblobs` in CIE $L^*a^*b^*$ space at `max_working_dim = 3200`. Stage 2 extracts tight `crop_pad = 0.0` leaf crops with `Leaf_Segmenter` `retina_masks: true` and `report.masks.subtract_holes: true`, isolates the primary focal `Leaf` (`cls == 0`) instance (`_largest_component >= 64` px) alongside rachis-bridged secondary pinna components (`>= 64` px connected strictly through `Petiole`), subtracts holes (`lamina = silhouette & ~hole`), and enforces LeafMachine3's midvein Voronoi bilateral symmetry gate (`bilateral_dice >= 0.70` and `|si_a| < 0.35` for entire blades; `bilateral_dice >= 0.45` and `|si_a| < 0.48` for dissected blades).
* **Native LeafMachine3 Delegation and Anatomical Zones:** Step 02 delegates directly to native LeafMachine3 core and reporting modules (`compute_ect` and `ect_product_for` alongside `render_leaf_products`, `measure_petiole`, `compute_measurements`, `prepare_mask`, `extract_contour`, `resample_closed` and `polygon_morphology` alongside `length_width_from_box`) with collision-free 31-keypoint mapping (`midvein_1..15` to `midvein_0..14` and `petiole_1..5` to `petiole_0..4`) and $32 \times 360$ ECT matrices. Post-segmentation anatomical `leaf_zone` (`'basal'` vs. `'cauline'`) classification (`classify_leaf_zone_anatomical`, `leaf_zone_confidence`, `dist_from_crown_norm`) tags all valid segmented leaves per `plant_individual_id`. Per-plant (`plant_individual_id`) adaptive blade floor $\min(0.75, \max(0.15, 0.25 \times \text{median\_area}))$ and relative area floor ($0.15 \times \max\text{area}$) run without a sheet-wide leaf cap. Petiole $L_{\text{petiole}}$ is measured from crown $p_{\text{crown}}$ at $P_{75}$, scape height $H_{\text{plant}}$ accounts for bent stems, and rosette backgrounds are masked to `[242, 239, 230]`.
* **Nomenclatural Types and Authority:** Strict `identifiedBy` isolation (`parse_determiner_tier()` and `classify_determiner_tier()`) evaluates determiners independently of `recordedBy`, matches curated North American *Packera* specialists (`PACKERA_SPECIALISTS` and `SPECIALIST_PATTERNS`), blocks non-person database adjustments (`"Nomenclatural Adjustment"` and `"Nomenclature update"` alongside `"Taxonomic update"` and `"Annotation"`), and blocks bare common surnames without initials. Multi-herbarium monographer loan protection in `apply_corpus_authority_tiers()` preserves `Tier_1_Gold` for specialists annotating across multiple species or herbaria even when `dateIdentified` is missing, whereas single-folder institutional batch-transfer demotion routes undated single-herbarium, single-species batch transfers ($\ge 25$ sheets, $\ge 10$ collectors, $\ge 85\%$ in 1 species at 1 institution where `recordedBy != identifiedBy`) from `Tier_1_Gold` to `Tier_2_Silver` for out-of-sample Mahalanobis and Confident Learning screening. Personal field collections (`recordedBy == identifiedBy`) and dated specialist annotations remain `Tier_1_Gold`. Preflight re-applies `apply_corpus_authority_tiers()` and filters `auto_neighbors` candidates against `^Packera\s+[a-z]{3,}$`. Ranks 2 and 1 remain exempt from uncertainty and date drop filters, so they survive spatial thinning and take priority in outgroups. Supervised anchors (`Tier_1_Gold`, `Tier_2_Silver`, promoted Bronze within $\chi^2_{0.80}$) fit models, whereas unpromoted Bronze receive $0.0$. Types receive retention immunity (`Tier_0_Type_Anchor`), extreme types ($> \chi^2_{0.99}$) are isolated from FastMCD, and taxon centers shrink toward type medoids ($\gamma_k$).
* **Strict Tier-1 EFA, Topological ECT and Dual Basal/Cauline Tracks (Step 03):** Batch SQL from `contour_xy_json` retains both `leaf_zone == 'basal'` and `leaf_zone == 'cauline'` intact `Tier_1_Direct` contours in `leaf_efa_harmonics`. Step 03 runs `coo_alignxax`, dynamic $H_{\text{opt}} \in [6, 24]$ ($\ge 99\%$ power), `rm_asym`, $k_{95}$ variance PCs, and $32 \times 360$ ECT alignment and SVD (`compute_leaf_ect_features`: `ECT_PC1..PC3`, `Cauline_ECT_PC1..PC2`, `ect_lobe_complexity`, `cauline_ect_lobe_complexity`, `ect_bilateral_asym`, `heteroblasty_ect_distance`). Type contours remain exempt from MCD filtering. Primary OTU harmonic aggregation per `(catalogNumber, plant_individual_id)` isolates pure basal rosette outlines ($w_{\text{basal}} = 1.0$, $w_{\text{cauline}} = 0.0$ when basal leaves are present, with cauline fallback when basal leaves are absent) while exporting orthogonal cauline and heteroblasty metrics (`cauline_leaf_count`, `cauline_solidity_med`, `cauline_dissection_index_med`, `basal_vs_cauline_length_ratio`, `basal_vs_cauline_solidity_delta`, `heteroblasty_efa_distance`, `heteroblasty_ect_distance`, `Cauline_PC1..PC3`, `Cauline_ECT_PC1..PC2`).
* **Morphometrics and Allometry (Step 04):** Step 04 preserves independent specimen coordinates for LOOCV and MANOVA while partitioning variance across Level 1 within-plant heteroblasty (unweighted clean basal primary OTU medians via `reconcile_step03_basal_otu_medians()`, paired with the orthogonal cauline and heteroblasty feature track), Level 2 $10\text{ km}$ conspecific spatial deme assignment (`assign_spatial_gathering_demes`), and Level 3 within-deme phenophase residualization (`residualize_within_deme_phenophase_plasticity`) and intraspecific $Q_{ST}$ covariance whitening (`whiten_intraspecific_deme_plasticity`). Whole and multi-island dissected individuals share a unified topology + foliar architecture projection (`.project_shared_topology_rows_step04`). Two-stage FastMCD reference anchor seeding fits the initial ellipsoid on Gold and Type anchors ($\chi^2_{0.95, p}$ for $n \ge \max(12, 5p)$) and screens Silver anchors at $\chi^2_{0.90, p}$, dynamically enabling bimodal whole/dissected sub-mode screening whenever a taxon's `Tier_1_Gold` cohort spans both entire and dissected basal foliage. Out-of-fold Confident Learning screens anchors via shrinkage posteriors and demotes violators (`is_confident_label_noise = TRUE`) to passive projection. Crossed-effects hierarchical Bayesian authority weights evaluate leave-one-out PC concordance unconditionally when $G \ge 2$, which combines determiner reliability $\theta^{\text{det}}_d$ and herbarium reliability $\theta^{\text{inst}}_h = \frac{4.0 \cdot 0.85 + \sum_{i \in h} c_i}{4.0 + n_h}$ in log-odds space with Raykar multiplicative updates. Canonical GMM relabeling fixes Cluster 1 ($c^* \equiv 1$) to the nomenclatural type medoid or highest-weighted Gold core while `compute_type_specimen_morph_control()` evaluates `is_typical_morphotype` per species ($c^*_k$), with $N_{\text{eff}}$-scaled Bayes Factors ($2\Delta\text{BIC} \cdot N_{\text{eff}} / N_{\text{core}}$). Feature pools incorporate foliar architecture and ECT descriptors alongside heteroblasty metrics (`blade_length_to_width_ratio`, `petiole_to_blade_ratio`, `basal_vs_cauline_length_ratio`, `basal_vs_cauline_solidity_delta`, `heteroblasty_efa_distance`, `heteroblasty_ect_distance`, `cauline_solidity_med`, `cauline_dissection_index_med`, `cauline_ect_lobe_complexity`, `Cauline_PC1..PC3`, `ECT_PC1..PC3`, `Cauline_ECT_PC1..PC2`, `ect_lobe_complexity`, `dissection_index`, `solidity`). Step 04 applies soft Gaussian geographic range-envelope log-priors ($3.5^\circ$ MAD floor), Klingenberg allometric slope homogeneity (`lm.rrpp`), Horn/Williams-Titus subspace selection, shrinkage CDA with honest LOOCV, and Open-Set Recognition (`min_congener_mahal_d2` and `min_congener_taxon` alongside `open_set_novelty_p`).
* **Spatial RF and *Locus Classicus* (Step 05):** Step 05 passively projects non-Tier-1 specimens lacking a Step 04 `gmm_cluster` (`is_missing_gmm_cluster`). It extracts 19 BioClim + 0 to 15 cm edaphics with uncertainty-gated type extraction ($\le 2000\text{ m}$ edaphic, $\le 10000\text{ m}$ climatic) and proximate Gold fallback ($\le 150\text{ km}$). Predictor gating enforces VIF $< 5.0$ and $|r| < 0.70$ alongside RF importance top 85%, followed by Spatial Block CV ($0.5^\circ$) with weights `[0.25, 4.0]` and MaxEnt + Spatial RF ensembles.
* **Consensus Triage and Complexes (Steps 06 to 07):** Step 06 weights modalities via out-of-fold $\kappa_m$ and circular anthesis DOY windows. It propagates sibling ramet morphology across multi-plant sheets (`catalogNumber`), requires observed or sheet-propagated leaf morphology before scoring `Putative_Hybrid_Introgression` / `Hybrid_Introgressant` (never imputing `cda_margin = 0.15` on leafless ramets), and enforces same-sheet (`catalogNumber`) gathering coherence across sibling `plant_individual_id` ramets. Stage 1 (`Misidentification_Reassign`) and relative Open-Set congener reassignment (`congener_osr_reassign`: $\chi^2_{0.90, p}$, $D^2_{\text{Mahal}}(k') < 0.70 \cdot D^2_{\text{Mahal}}(y_i)$, and $D^2_{\text{Mahal}}(y_i) > \chi^2_{0.95, p}$) run strictly before Stage 3 (`Putative_Cryptic_Species`) with calibrated CDA thresholds (`0.72` / `0.68` / `0.62`) and radial edaphic fallback alongside orthogonal 1-vote-per-modality Rule B (`vote_morph` + `vote_edaph`) with morphological concordance protection (`cda_prob >= 0.65`). The Population-Cohesion Lineage Gate requires `cryptic_cluster_cohesion_pass == TRUE` ($\ge 5$ independent collection events across $\ge 2$ collectors or herbaria, cluster-median `min_congener_mahal_d2` $> \chi^2_{0.95, 3}$, and $\ge 50\%$ concordant ecological or phenological divergence with $\text{BF} \ge 10.0$), whereas non-cohesive clusters route to `Confirmed_Species` (*sensu lato*) or `Ecophenotypic_Plasticity` alongside `Subspecies_Ecotype`. Rule A enforces type immunity (`Confirmed_Type_Control`), whereas Rule B governs reassignment and Rule C locks *sensu stricto* morphotypes ($c^*_k$). Step 07 executes unsupervised graph modularity (Leiden/Louvain) and Ward.D2 clustering across North American *Packera*.
