1. EXECUTIVE OVERVIEW & PROBLEM RESOLUTION
--------------------------------------------------------------------------------
In dried herbarium vouchers of Packera dubia, basal leaf petioles terminate directly 
at the caudex (root crown), physically merging with fibrous roots and rhizomes. 
Because both structures consist of dark, pressed, fibrous plant material without high-contrast 
color boundaries, naive single-point prompts cause SAM 2 (Segment Anything Model 2) to 
bleed across the caudex and lump roots, stems, and petioles into a single mask.


This guide provides the complete protocol for using the upgraded precision SAM 2 annotator 
(`scripts/annotation_and_training/annotate_with_sam2.py`), which incorporates five botanical constraint 
and inspection mechanisms:
  a. Bounding Box Prompts (Shift + Drag): Restricts SAM 2 attention strictly within the targeted lamina/petiole.
  b. Negative Exclusion Points (Right-Click): Explicitly forces roots, overlapping blades, or background out of the mask.
  c. Multimask Proposal Cycling (Tab): Cycles through SAM 2's 3 hierarchy levels (sub-lobe vs. blade vs. clump).
  d. Two-Click Knife Slicing ('k'): Performs clean, straight dissections across the petiole-caudex junction.
  e. Morphological Margin Tuning ('+' / '-'): Provides 1-pixel binary dilation/erosion to dial in fuzzy tomentose margins.


Following this protocol, 50-100 vouchers can be cleanly annotated in under 2 hours to provide 
a gold-standard calibration dataset for LeafMachine2 PCD (PointRend) and YOLOv8/YOLOv11 instance segmentation.

3. BOTANICAL CLASS ONTOLOGY (7-CLASS SCHEMA)
--------------------------------------------------------------------------------
Ensure `data/dataset_config.yaml` is configured with the dedicated 7-class botanical schema:


Class ID | Class Name           | Botanical Definition & Diagnostic Landmarks
---------|----------------------|-----------------------------------------------------------
   0     | basal_leaf_blade     | Expanded laminar portion of basal leaves (crenate/serrate)
   1     | leaf_petiole         | Narrow foliar stalk connecting caudex to the basal blade
   2     | cauline_leaf         | Sessile, lyrately-pinnatifid leaves on the flowering stalk
   3     | cauline_stem         | Main vertical flowering stalk / scape / peduncle
   4     | root_rhizome         | Subterranean dark fibrous roots, rhizomes, and rootlets
   5     | basal_rosette_clump  | Dense, overlapping basal rosette center / crown
   6     | capitulum            | Inflorescence head / cylindrical involucre / phyllaries

  --output-dir PATH       Directory for intermediate YOLO-format mask coordinate texts and PNG masks (default: data/raw_annotations)
  --output-coco PATH      Destination path for standardized COCO JSON dataset (default: data/annotations/packera_train_coco.json)
  --tier {1,2,3,all}      Filter vouchers by determiner authority tier (default: '1' for Tier 1 Gold monograph authorities; 'all' for all 5347 vouchers)
  --vouchers-csv PATH     Path to curated vouchers metadata table (default: data/tables/curated_vouchers.csv)
  --single-image PATH     Target a specific herbarium voucher image for focused editing
  --voucher ID            Jump directly to a specific voucher ID or filename (e.g. --voucher 1048)
  --index NUM             Jump directly to a 1-based voucher sheet number (e.g. --index 5)
  --resume-last           Automatically resume from the most recently annotated voucher sheet (within active tier)
  --resume-unannotated    Automatically jump to the first unannotated voucher sheet in sequence (within active tier)
  --checkpoint PATH       Path to SAM 2 Hiera weights (default: models/checkpoints/sam2_hiera_large.pt)
  --config CONFIG         SAM 2 model architecture configuration file (default: sam2_hiera_l.yaml)
  --export-coco           Compile and export COCO dataset from existing masks in headless mode
  --masks-dir PATH        Source masks directory for headless --export-coco compilation
  --val-split FRACTION    Validation partition fraction (e.g., 0.15 for 15% val split)

Navigation & Viewport Controls:
  - Mouse Wheel:         Cursor-centered zoom in / out (smooth 1.0x to 16.0x magnification).
  - Middle-Click Drag:   Smooth viewport pan across high-resolution herbarium scans.
  - Space + Left-Drag:   Alternative smooth viewport pan.
  - 'f':                 Fit to screen (resets zoom to 1.0x and centers sheet).
  - Click '[< Prev (b)]' / 'b' / Left Arrow: Navigate to previous voucher sheet WITHOUT saving or modifying annotations.
  - Click '[Next > (n)]' / 'n' / Right Arrow: Navigate to next voucher sheet WITHOUT saving or modifying annotations.

Segmentation & Prompting:
  - Left-Click:          Add positive foreground prompt point (Green landmark).
  - Right-Click:         Add negative exclusion prompt point (Red landmark).
  - Ctrl + Z / 'z' / Bksp / NumPad . / Del: Undo last prompt point (removes single inclusion or exclusion point and re-runs SAM 2 in real time; also clickable via the top-right '[Undo Pt (Ctrl+Z)]' HUD button).
  - Shift + Left-Drag:   Draw bounding box constraint (restricts SAM 2 search space).
  - Tab / NumPad /:      Cycle through the 3 SAM 2 multimask candidate granularities (sub-lobe vs. blade vs. clump).
  - 'k':                 Two-click knife tool for petiole/caudex slicing (Click 1: start cut, Click 2: end cut; press 'k' again to toggle off).
  - '+' / '=' / NumPad +: Single-pixel binary dilation (expands mask margin outward into arachnoid tomentum).
  - '-' / '_' / NumPad -: Single-pixel binary erosion (contracts mask margin inward from background glare/bleed).
  - 'p':                 Toggle polygon lasso mode (Left-Click to trace custom vertices, Enter/Right-Click to finalize).

Inspection & Visibility:
  - 'o' / NumPad *:      Toggle view mode: semi-transparent mask fill vs. 1-pixel boundary contour line (for crenation inspection).
  - Hold 'v':            Hold-to-peek: Temporarily hides all mask and prompt overlays to reveal bare specimen pixels.
  - '[' and ']':         Decrease / increase mask overlay alpha transparency (steps of 0.1, clamped between 0.10 and 0.90).
  - Pre-populated Masks: Existing annotations automatically render with distinct colors and counts when moving between sheets.

Commit & Session Management:
  - Keys '0'–'6' / NumPad '0'–'6': Instant botanical class assignment and instance commit (commits active mask to class ID 0–6; works with NumLock ON or OFF).
  - 'u':                 Undo last committed instance on current sheet.
  - 'c':                 Clear current candidate points, bounding box, knife line, and candidate masks.
  - Click '[Save (s)]' / 's' / Enter / NumPad Enter: Save current sheet annotations (fast sub-10ms save to YOLO txt and PNG masks).
  - 'q' or Esc:          Save modified sheet annotations and quit application cleanly (syncs COCO JSON on exit).
  - Window 'X' Button:   Safely close window (saves if dirty, syncs COCO JSON on exit).




5. BOTANICAL BOUNDARY BEST PRACTICES FOR DENSE PACKERA ROSETTES
--------------------------------------------------------------------------------
The basal rosettes of Packera dubia present extreme morphometric challenges: petiole bases 
densely crowd at the caudex, blades overlap at acute angles, margins possess subtle 
crenate-dentate teeth, and petioles/sinuses often bear flocculent white tomentum (pubescence). 
Adhere to the following operational protocols to ensure research-grade segmentation:

A. Disentangling Clumps via Multimask Proposal Cycling (Tab):
   - When placing a positive point on a basal blade that overlaps another, SAM 2 frequently generates 
     an ambiguous response. By default, the top-confidence mask may capture the entire multi-leaf clump.
   - Do NOT immediately add numerous negative points. Instead, press `Tab` to cycle through the 3 
     internal proposal granularities computed by SAM 2:
       * Granularity 1 (Sub-part): Single leaf lobe or crenation tooth.
       * Granularity 2 (Part): The isolated individual leaf blade (lamina).
       * Granularity 3 (Whole): The aggregated rosette clump.
   - In 85% of crowded cases, cycling with `Tab` reveals the clean, isolated blade mask instantly.

B. Validating Tooth and Sinus Margins via Contour-Only Mode ('o'):
   - Standard solid mask overlays can obscure fine crenate/dentate margin architecture and secondary teeth.
   - Press `o` to switch from filled mask rendering to a crisp 1-pixel boundary contour line.
   - Inspect the contour against the raw leaf margin at 4.0x–8.0x zoom:
       * Verify that tooth apices and sinus depths are faithfully traced without bridging adjacent teeth.
       * Hold `v` to peek the bare image and check whether apparent margin irregularities are true teeth 
         or pressed petiole fragments of overlapping leaves.
   - Press `o` again to return to filled overlay mode before committing.

C. Caudex Separation via the Two-Click Knife Tool ('k'):
   - Where the petiole inserts into the caudex or merges into subterranean rhizome tissue, 
     SAM 2 cannot infer an anatomical boundary because the pressed plant tissue is continuous and dark.
   - Press `k` to activate Knife Mode.
   - Click once at one edge of the petiole-caudex junction, then click across the opposite edge.
   - The annotator severs the mask along the cut line and automatically prunes away the disconnected 
     fragment, retaining only the target segment containing your prompt point(s).
   - Upon completing the cut, the annotator automatically returns to SELECT mode so you can press '1' 
     to commit the clean `leaf_petiole` instance immediately.

D. Managing Arachnoid Tomentum with Morphological Margin Tuning ('+' / '-'):
   - *Packera dubia* and *Packera tomentosa* display woolly, arachnoid pubescence (tomentum) along 
     the petiole and blade margin. Depending on lighting, SAM 2 may either under-segment by clinging 
     to the green/brown lamina core or over-segment into white woolly halos.
   - Press `+` to apply a single-pixel 3x3 binary dilation if the mask cuts inside the true laminar margin.
   - Press `-` to apply a single-pixel 3x3 binary erosion if the mask bleeds into diffuse edge hairs or background paper.




6. STEP-BY-STEP ANNOTATION PROTOCOL
--------------------------------------------------------------------------------
For each herbarium voucher sheet:


Step A: Viewport Navigation & Basal Cluster Orientation
  - Hover the cursor over the basal rosette and roll the Mouse Wheel up to zoom in (2.0x to 8.0x).
  - Middle-Click Drag (or hold Space + Left Drag) to center the caudex and basal leaves in view.
  - Press 'f' at any time to reset zoom to 1.0x and survey the full voucher sheet.


Step B: Annotating Basal Leaf Blades & Petioles
  1. Hold Shift + Left-Drag a bounding box around the target leaf blade, or Left-Click directly in the 
     mid-lamina.
  2. Press Tab to select the individual blade candidate proposal over the clump proposal.
  3. Press 'o' to inspect margin contours along the crenations. If hairs cause bleeding, press '-' once.
  4. Press '0' to instantly commit the mask as `basal_leaf_blade` (Green).
  5. Left-Click along the corresponding petiole. If it bleeds into the caudex, press 'k' and click two 
     points across the petiole base to sever it.
  6. Press '1' to instantly commit as `leaf_petiole` (Mint Green).


Step C: Annotating Roots & Rhizomes
  1. Hold Shift + Left-Drag a bounding box around the subterranean root mass at the base of the sheet.
  2. Right-Click on overlapping petiole bases if any foliar tissue is captured.
  3. Press '4' to save as `root_rhizome` (Red/Brown).


Step D: Annotating Cauline Stems & Leaves
  1. Left-Click along the vertical flowering scape / peduncle. Press '3' for `cauline_stem` (Orange).
  2. Left-Click individual stem leaves; press Tab if needed, then press '2' for `cauline_leaf` (Yellow-Green).


Step E: Annotating Capitula (Heads)
  1. Left-Click each involucre / flower head in the synflorescence.
  2. Press '6' to save as `capitulum` (Yellow).


Step F: Save and Advance
  - Press Enter (or 'n').
  - The script automatically writes normalized YOLO polygon coordinates to `data/raw_annotations/{id}.txt`, 
    exports instance mask PNGs to `data/raw_annotations/masks/{id}_*.png`, updates the incremental 
    COCO dataset JSON (`data/annotations/packera_train_coco.json`), and loads the next voucher.
  - Use 'b' to navigate back to previous vouchers if adjustments are needed.
