IMPORTANT NOTICE — ARCHIVED / OPTIONAL STANDALONE UTILITY:
--------------------------------------------------------------------------------
The automated production pipeline (`./run_pipeline.sh` / `python main.py`) does NOT
require manual SAM 2 annotation or custom LeafMachine3 retraining.
By default, Phase 2 (`02_segment_and_extract.py` and `configure_leafmachine3.py`)
operates out of the box using locked LeafMachine3 ONNX Runtime weights:
  - Stage 1 Detector & Specimen Segmenter: `lm3_plant_detector__yolo26x_det_1280` +
    `lm3_specimen_segmenter__unetpp_effb7_1024_dinov3_vith16plus_2048_selftrain` +
    3-model Ruler Classifier & Tick-Lattice Solver (`min_blade_area_cm2: 0.75`).
  - Stage 2 Segmenter & Pose: `lm3_leaf_segmenter__yolo26x_seg_1024` +
    `lm3_landmark_detector__yolo26x_pose_640` paired with Otsu boundary-continuity
    lobe rejection (`max_tissue_border_ratio: 0.15`) and classical dimensionless
    shape gatekeeping (`Solidity >= 0.72`, `Circularity >= 0.25`, `Extent >= 0.35`,
    plus pinnatifid and bipinnatisect dissection gates).

The interactive SAM 2 annotator (`scripts/annotation_and_training/annotate_with_sam2.py`)
documented below is retained strictly as an optional standalone utility for custom
benchmark creation or exploratory mask curation.


1. STANDALONE UTILITY OVERVIEW
--------------------------------------------------------------------------------
In dried herbarium vouchers of Packera dubia, basal leaf petioles terminate directly
at the caudex (root crown), physically merging with fibrous roots and rhizomes.
When curating custom ground-truth benchmarks outside the main automated pipeline,
`scripts/annotation_and_training/annotate_with_sam2.py` provides six optional
interactive mechanisms:
  a. Automated LM3 + SAM 2 Pre-Labeling (--prelabel-with-lm3)
  b. Bounding Box Prompts (Shift + Drag)
  c. Negative Exclusion Points (Right-Click)
  d. Multimask Proposal Cycling (Tab)
  e. Two-Click Knife Slicing ('k')
  f. Morphological Margin Tuning ('+' / '-')


2. OPTIONAL STANDALONE INVOCATION
--------------------------------------------------------------------------------
# Launch interactive SAM 2 annotator (optional standalone utility):
source .venv/bin/activate
python scripts/annotation_and_training/annotate_with_sam2.py \
    --images-dir data/raw_vouchers \
    --output-dir data/raw_annotations \
    --output-coco data/annotations/packera_train_coco.json \
    --prelabel-with-lm3

# Headless compilation of single-leaf cropped COCO dataset:
python scripts/annotation_and_training/annotate_with_sam2.py \
    --export-coco \
    --masks-dir data/raw_annotations/masks \
    --images-dir data/raw_vouchers \
    --crops-dir data/annotations/lm3_leaf_crops \
    --output-coco data/annotations/packera_train_coco.json \
    --val-split 0.15


3. HOTKEY REFERENCE (OPTIONAL INTERACTIVE GUI)
--------------------------------------------------------------------------------
Navigation & Viewport Controls:
  - Mouse Wheel:         Cursor-centered zoom in / out (smooth 1x to 16x magnification).
  - Middle-Click Drag:   Smooth viewport pan across high-resolution herbarium scans.
  - Space + Left-Drag:   Alternative smooth viewport pan.
  - 'f':                 Fit to screen (resets zoom to 1x and centers sheet).
  - 'b' / Left Arrow:    Navigate to previous voucher sheet without saving.
  - 'n' / Right Arrow:   Navigate to next voucher sheet without saving.

Segmentation & Prompting:
  - Left-Click:          Add positive foreground prompt point.
  - Right-Click:         Add negative exclusion prompt point.
  - Ctrl + Z / 'z':      Undo last prompt point.
  - Shift + Left-Drag:   Draw bounding box constraint.
  - Tab:                 Cycle through the 3 SAM 2 multimask candidate granularities.
  - 'k':                 Two-click knife tool for petiole/caudex slicing.
  - '+' / '-':           Single-pixel binary dilation / erosion.
  - 'o':                 Toggle semi-transparent mask fill vs. 1-pixel contour line.
  - Keys '0'–'1':        Commit basal_leaf_whole (0) or basal_leaf_partial (1).
  - 's' / Enter:         Save current sheet annotations.
  - 'q' / Esc:           Save modified sheet annotations and quit cleanly.
